# Academia LATAM

Repositorio estratégico del proyecto de una **EdTech independiente**, con sede en **México** y orientada a **Latinoamérica**. Acá dejamos asentadas las decisiones, investigaciones, contactos y avances del proyecto.

> "Academia LATAM" es el nombre de trabajo del repositorio. La marca definitiva todavía no está decidida (ver [05-marca/naming.md](05-marca/naming.md)).

## Qué ya está definido

| Tema | Decisión |
|---|---|
| Independencia | Proyecto separado de UTN y de Aprender Online (contenidos, marcas y bases de datos separados). |
| Sociedad | Socios potenciales: **Fabricio** (México), **Radsé** y **Matías**. |
| Sede | Empresa constituida en **México**. |
| Mercado | México como primer gran mercado; **LATAM** como mercado real. |
| Modelo | **Escuela especializada** (Modelo B) en IA + Business + Marketing + tecnología aplicada. |
| Marca | Marca propia como activo principal. La universidad es **partner académico**, no la marca principal. |
| Tipo de oferta | **Educación continua** con aval universitario (no programas con RVOE). |
| Universidades a investigar | Anáhuac México, La Salle CDMX, Ibero CDMX, Universidad Panamericana. |
